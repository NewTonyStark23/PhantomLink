# PhantomLink
PhantomLink is a dark-mode device extension tool that transforms your tablet into a precision touchpad, drawing tablet, or interactive touch display. 
It integrates five layers of capability—including stealth networking, 
high-refresh-rate display extension, 
touch input, resource pooling, 
and GPU acceleration—all over a single USB connection, 
effectively turning your phone or tablet into a full PC peripheral without carrier visibility or overheating risks.
